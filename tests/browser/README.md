# 浏览器交互测试

运行 `npm run test:e2e` 会构建真实 Go 服务，启动临时本地模型 HTTP 服务，然后以 Chrome/Chromium 遍历页面。测试使用独立 Cookie 用户空间，数据目录在退出时清理。浏览器结果包含逐项断言、完整截图、JSON 汇总和 HTML 图库。

| 套件 | 覆盖交互 |
| --- | --- |
| desktop | 三个初始建议、空输入、Enter/Shift+Enter/IME、重复提交、引用及清除、深入/发散切换、取消提问、父节点/相邻节点/图节点键盘导航、预测节点、多选及清除、合并、图定位、收藏与取消、完成标记与取消、归档与刷新恢复、复制回答及剪贴板失败回退、复制节点、导出内容、删除取消与确认、链接与分享码导入、只读分享、偏好保存/清空/校验、弹窗关闭/Escape/遮罩、迟到会话与收藏请求、根话题、新建与切换会话 |
| mobile | 390px 手机布局、侧栏与遮罩、四向真实触摸手势、双指总览、原生缩放隔离、图选择和定位、焦点卡片可见性、长回答内部滚动、帮助与设置弹窗、偏好保存、320px 窄屏回答与提问、横屏短侧栏、缩小可视区域下的提问、减少动画 |
| recovery | 模型临时/持续/格式错误、停止及带引用重试、合并停止重试、生成时刷新、会话创建失败、发送失败草稿恢复、损坏 SSE、无效分享导入的可见提示、私有会话隔离、分享副本独立继续、失效链接、新启动连接失败后重连 |

`fixture.mjs` 提供真实 OpenAI 兼容响应与可控故障。`[slow]` 延迟三秒，`[once]` 对同一完整提示词首次返回 503，`[fail]` 持续返回 503，`[invalid]` 返回不合格式的模型内容，`[long]` 生成长回答用于滚动测试。应用请求仍经过正常路由、模型解析、卡片存储和 SSE 回传。

手机验证采用 Chromium 触摸设备仿真。短视口用来检查软键盘占用屏幕后的布局，真实 iOS/Android 键盘及 Safari 需要相应设备环境。模型网络协议在本地测试服务上验证，外部服务的密钥和回答质量需针对实际部署单独验证。

调试时可以先启动 `node tests/browser/fixture.mjs`，然后设置其输出地址为 `GITCHAT_TEST_URL` 运行单个套件。若外部地址指向已有应用，测试会在该应用中新建测试用户和对话。
